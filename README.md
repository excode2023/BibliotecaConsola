# Sistema de Biblioteca

## Descripción

Aplicación de consola desarrollada en C# y .NET 10 para gestionar una biblioteca.

## Objetivo

Permitir al bibliotecario:

- Registrar libros.
- Registrar usuarios.
- Buscar libros.
- Gestionar préstamos y devoluciones.

## Tecnologías

- C#
- .NET 10
- PostgreSQL (próximamente)

## Arquitectura

El proyecto estará organizado utilizando separación de responsabilidades:

- Models
- Services
- Repositories
- UI
